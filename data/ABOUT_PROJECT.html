Project Overview

Scaffold-ETH 2 Starter dApp

This repository is a developer-oriented Ethereum starter stack built with Hardhat, Next.js, and modern web3 tooling. It is designed to become a polished release-ready starter for contract-driven applications.

Core architecture

  • Backend: Solidity + Hardhat + Rocketh deploy scripts
  • Frontend: Next.js App Router + React 19 + TypeScript
  • Web3 stack: Wagmi, Viem, RainbowKit, @scaffold-ui/components, DaisyUI
  • Deployment: Local chain support with network config for live chains

Why this repo matters

  • Great foundation for token apps, NFT experiences, staking, or DAO tooling.
  • Strong developer onboarding with built-in commands and starter UIs.
  • Easy to extend while preserving current stack and workflow.

Detailed project scope

Smart contract layer

Enhance the current greeting contract and add one or more real-world Solidity examples such as token minting, NFT drops, staking, or subscription payments. Focus on security, access control, and test coverage.

Frontend polish

Build an intuitive interaction page that lets users connect wallets, read contract state, submit transactions, and receive live feedback. Make the experience visually appealing and easy to use.

Release readiness

Prepare the project for launch by adding documentation, a deployment workflow, and a launch checklist. Ensure the repo is ready for contributors and public users.

Integration support

Wire frontend contract metadata automatically so deployment results are reflected without manual editing. Add helpers or scripts to update contract address/ABI config.

What’s included today

  • Starter contract: `packages/hardhat/contracts/YourContract.sol` with greeting state, premium flag, counters, and owner withdraw.
  • Deploy script: `packages/hardhat/deploy/00_deploy_your_contract.ts` using Rocketh and named accounts.
  • Frontend starter page: `packages/nextjs/app/page.tsx` with wallet address display and navigation hints.
  • Empty frontend contract metadata file: `packages/nextjs/contracts/deployedContracts.ts` ready to receive generated addresses.
  • Config file: `packages/nextjs/scaffold.config.ts` with local network defaults and API key placeholders.
